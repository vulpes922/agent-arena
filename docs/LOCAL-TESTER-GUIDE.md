# Local tester guide

The current guide is [Run Agent Arena on your computer](SETUP.md).

It includes prerequisites, macOS setup, Windows through WSL 2, ChatGPT sign-in, restarting, updates, and troubleshooting. For controls, model choices, saved conversations, and limitations, read the [user guide](USER-GUIDE.md).

Use the `local` branch for live debates. Native Windows/PowerShell execution is not currently supported by the prototype's agent runner; follow the WSL instructions.
